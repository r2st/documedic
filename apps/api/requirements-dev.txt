# Development and CI dependencies. Deliberately NOT installed by the Dockerfile.
#
# These used to live at the bottom of requirements.txt, which the Dockerfile installs whole —
# so pytest, ruff, mypy and their dependency trees were being built into the production image
# alongside uvicorn. Splitting them out is both smaller and narrower: the running container no
# longer carries a test runner, a linter, a type checker, or pytest's own advisory
# (PYSEC-2026-1845, a /tmp directory-permissions issue that has no business being reachable in
# a clinical deployment).
#
#   pip install -r requirements.txt -r requirements-dev.txt

-r requirements.txt
